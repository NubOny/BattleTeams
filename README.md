# BattleTeams

O BattleTeams é um app de criação de times de forma aleatória ou de forma balanceada.

Sabe quando vocẽ vai jogar futebol, paintball ou até mesmo um trabalho em equipe onde os membros sempre escolhem as mesmas pessoas ou dão preferencia para alguem por algum motivo? Esse apliativo foi criado com o intúito de acabar com esse problema de forma rápida e prática.

---
## Principais funcionalidades

1. Modos de Divisão
    1.1 - Modo aleatório - Divide de forma aleatória, não ligando para nivel de habilidade ou algo do tipo
    1.2 - Modo equilibrado - Divide de forma equilibrada com base no nível de habilidade de cada usuário

2. Salvamento de dados
    2.1 - Salvamento de grupos - Salva os membros de um time criado para não precisar ficar adicionando toda vez (Exemplo: 'Galera do Paintball').
    2.2 - Salvamento de times - Caso você queira guardar algum time que foi gerado em uma sessão
    2.3 - Salvamento de Sessão - Salva todos os times criados em uma sessão

    Obs.: O aplicativo não dispõe de banco de dados, os salvamentos são realizado por meio de dados de permanência em um arquivo JSON.
